# Шпаргалка редактора · Храмы Гаспры

**Вход:** `адрес-сайта/admin` → почта и пароль → «Войти».

| Задача | Где | Что нажать |
|---|---|---|
| **Расписание на неделю** | Главный экран → «Расписание на неделю» → «Следующая» | «Заполнить из шаблона» → поправить → **«Опубликовать неделю»** |
| **Расписание из сообщения** | «Вставить расписание текстом» | вставить → «Разобрать и показать» → проверить красное → **«Сохранить»** |
| **Отменить службу** | Главный экран, у службы | **«Отменить»** (вернуть — «Вернуть») |
| **Перенести службу** | Главный экран, у службы | «Перенести» → новое время → **«Сохранить»** |
| **Новость с фото** | «Новая новость» | заголовок, «Коротко», обложка, текст → (галочка «В Telegram») → **«Опубликовать изменения»** |
| **Фотоальбом** | «Новый фотоальбом» | название, дата → перетащить все фото → **«Опубликовать»** |
| **Записки** | «Заявки» | «Распечатать новые записки» → у заявки статус «Выполнена» → **«Сохранить»** |
| **Текст страницы** | «Текстовые страницы» | открыть → поправить блок → **«Опубликовать изменения»** |
| **Телефон, реквизиты, QR** | «Настройки сайта» | нужная вкладка → **«Сохранить»** |
| **Объявление на сайте** | Главный экран → «Объявление на сайте» | галочка, текст → **«Сохранить объявление»** |
| **Сбор пожертвований** | Главный экран → «Сбор пожертвований» | суммы → **«Сохранить сбор»** |

**Запомнить:**
- Время пишем так: `9:00`, `17:30`. Храм в тексте — в скобках: `(Нины)`, `(Стена)`.
- Черновики сохраняются сами. Значок «глаз» — посмотреть, как будет на сайте.
- Удалённое лежит в **корзине 30 дней** — можно восстановить.
- У каждого фото — описание, что на нём изображено.
- Заявки содержат персональные данные: не пересылать, не публиковать.
