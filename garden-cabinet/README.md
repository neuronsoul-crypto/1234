# Пристенный уличный шкаф для садового инвентаря

Проект водонепроницаемого шкафа-пристройки к стене дома: 17 листов A4 (альбомная ориентация).

**Файл проекта:** [`shkaf-sadovyj-proekt.pdf`](shkaf-sadovyj-proekt.pdf)

| | |
|---|---|
| Корпус | 1540 × 685 мм, высота 2.44 м |
| Внутри | 1386 × 498 мм, высота 1.76–2.04 м |
| Двери | 2 накладные створки по 720 мм, проём 1310 × 1715 |
| Кровля | односкатная 14°, гибкая черепица по ОСП-3 и самоклеящемуся подкладочному ковру |
| Стены | каркас 45×45, ветро-влагозащитная мембрана, «американка» 20×140 |
| Основание | 6 бетонных опор, пол на 273 мм над землёй |
| Материалы | ≈ 85 тыс. ₽ по ценам Крыма (октябрь 2026), экономный вариант ≈ 74 тыс. ₽ |

Состав: виды, разрезы, каркас, панели стен и стропило, узлы 1–5 (примыкание к дому,
карниз и водосток, низ стены, порог, притворы дверей), двери, внутреннее оснащение,
спецификация материалов, смета по ценам Крыма, раскрой, порядок сборки, отделка и обслуживание.

## Пересборка PDF

Все размеры задаются в `src/geom.py`, раскрой и закупка считаются в `src/parts.py`,
цены сметы — в `src/prices.py`.

```
pip install reportlab
python3 src/build.py shkaf-sadovyj-proekt.pdf
```
