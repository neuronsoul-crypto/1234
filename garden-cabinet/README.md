# Пристенный шкаф для садового инвентаря — эконом-вариант

Водонепроницаемый шкаф из профнастила у стены дома, бюджет на материалы до 20 000 ₽ (цены Крыма).
12 листов A4, альбомная ориентация.

**Файл проекта:** [`shkaf-sadovyj-proekt.pdf`](shkaf-sadovyj-proekt.pdf)

| | |
|---|---|
| Корпус | 1020 × 570 мм, высота 2.25 м |
| Внутри | 910 × 455 мм, высота 1.85–1.97 м; 6–8 инструментов до 1.7 м |
| Двери | 2 накладные створки, проём 910 × 1703 мм |
| Кровля | один лист профнастила С10 1150 × 763 мм, уклон 14°, свес 200 мм |
| Стены | профнастил С10 с полимерным покрытием по каркасу 45×45 |
| Основание | 3 пескоблока, пол ОСП-3 12 мм на 207 мм над землёй |
| Материалы | ≈ 17 780 ₽ с доставкой и резервом 10 % (Крым, октябрь 2026) |

Состав: виды, разрезы, каркас, узлы 1–5 (примыкание к дому, карниз, низ стены, порог, притворы),
двери и раскрой профнастила, спецификация и раскрой бруска, смета, порядок сборки, обслуживание.

Предыдущий вариант (вагонка, гибкая черепица, ≈ 85 тыс. ₽) — в истории git.

## Пересборка PDF

Размеры — `src/geom.py`, детали и раскрой — `src/parts.py`, цены — `src/prices.py`.

```
pip install reportlab
python3 src/build.py shkaf-sadovyj-proekt.pdf
```
