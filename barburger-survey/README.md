# Барбургер — анкета гостя + админка

Гостевая анкета (для QR-кода на столах) и защищённая паролем админ-панель с выгрузкой результатов в Excel.

## Установка и запуск

```bash
cd barburger-survey
npm install
ADMIN_PASSWORD="ваш-надёжный-пароль" SESSION_SECRET="случайная-длинная-строка" npm start
```

Сайт откроется на `http://localhost:3000/` (или на порту из переменной `PORT`).

- Анкета для гостей: `/`
- Вход в админку: `/admin/login.html`

## Переменные окружения (обязательно задать на сервере)

| Переменная        | Назначение                                                                 |
|--------------------|-----------------------------------------------------------------------------|
| `ADMIN_PASSWORD`   | Пароль для входа в админку. Без него используется пароль по умолчанию `barburger2026` — **обязательно смените его в проде**. |
| `SESSION_SECRET`   | Случайная строка для подписи сессионной cookie. Если не задать — генерируется заново при каждом перезапуске сервера, и все админы будут разлогинены. |
| `PORT`             | Порт сервера (по умолчанию `3000`).                                        |

## Где хранятся данные

Ответы гостей копятся в файле `data/responses.json` на сервере (просто список JSON-объектов). Файл создаётся автоматически при первом запуске. Для такого объёма анкет (сотни-тысячи в месяц) отдельная база данных не нужна.

**Важно:** при деплое убедитесь, что папка `data/` находится на персистентном диске (не удаляется при каждом деплое/перезапуске контейнера) — иначе результаты анкет будут теряться.

## Админка

На `/admin/login.html` — вход по паролю. После входа доступен `/admin/dashboard.html`:

- сводная статистика (средние оценки, NPS-индекс, распределения по всем вопросам);
- таблица всех ответов с постраничной навигацией;
- кнопка **«Скачать в Excel»** — выгружает `.xlsx` с двумя листами: «Ответы» (сырые данные по каждой анкете) и «Сводка» (агрегированная статистика).

## Деплой

Подойдёт любой хостинг с поддержкой Node.js (Render, Railway, VPS и т.п.):

1. Задать `ADMIN_PASSWORD` и `SESSION_SECRET` в переменных окружения хостинга.
2. Настроить персистентное хранилище для папки `data/`.
3. Команда запуска: `npm install && npm start`.
4. Привязать домен, сгенерировать QR-код на корневой URL сайта для размещения на столах.
