# Сайт храма-часовни вмч. Георгия Победоносца

Статический сайт по брендбуку «Разработка айдентики часовни» (П. Анастасия, Ф. Анна).
Сборка не нужна: обычные HTML/CSS/JS, можно положить на любой хостинг.

## Страницы

| Файл | Что на странице |
|---|---|
| `index.html` | Главная: о часовне, новости, ближайшее богослужение, ближайшие дни из расписания, цитата, как добраться |
| `raspisanie.html` | Полное расписание богослужений: фильтры, отметка «сегодня», печать |
| `duhovenstvo.html` | Духовенство: карточки и поиск |
| `o-chasovne.html` | История, летопись, смысл знака, фирменные цвета |
| `vystavki.html` | Выставки (пока примеры карточек) |

## Фирменный стиль

- **Цвета:** `#1A4780` (Чёрное море), `#FFF5EE` (морская ракушка), `#0A0A0A` (чёрный янтарь). Заданы переменными в начале `assets/css/style.css`.
- **Шрифт TAVR** (`assets/fonts/TAVR.woff2`) собран из алфавита на 2-м слайде брендбука: 33 прописные буквы, точка, дефис и «·». Строчные буквы показываются теми же прописными. Цифр и других знаков в шрифте нет, вместо них браузер берёт Andika. Если у дизайнеров есть исходный файл шрифта, просто замените `TAVR.woff2`.
- **Andika** — дополнительный шрифт из брендбука, подключается с Google Fonts.
- **Логотипы** векторизованы из PDF и лежат в `assets/img/`:
  - `logo-h*`, `logo-v*` — горизонтальная и вертикальная версии;
  - `sign*` — один знак;
  - `composition*` — «Церковь — корабль нашего спасения»;
  - без суффикса — чёрный с синим, `-light` — светлый для синего фона.
- **Паттерны и пейзаж** (`pattern-*.webp`, `landscape.webp`) взяты из брендбука.

## Как поменять расписание (пока без админки)

Расписание хранится в одном файле: `data/schedule.json`.

```json
{
  "updated": "2026-10-14",
  "note": "В расписании возможны изменения. Уточняйте по телефону.",
  "days": [
    {
      "date": "2026-12-09",
      "title": "Юрьев день. Престольный праздник",
      "type": "patronal",
      "services": [
        { "time": "08:00", "name": "Часы. Божественная литургия", "priest": "прот. Николай", "note": "" }
      ]
    }
  ]
}
```

- `date` — дата в формате `ГГГГ-ММ-ДД`.
- `title` — название праздника или памяти. Необязательное поле.
- `type` — тип дня, необязательное поле:
  - `great` — великий праздник;
  - `patronal` — престольный;
  - `feast` — праздник;
  - `memorial` — поминовение усопших.
- `services` — список служб; `time` и `name` обязательны, `priest` и `note` — по желанию.
- Порядок дней не важен, сайт отсортирует их сам. Прошедшие дни скрываются автоматически.

Новости хранятся так же, в `data/news.json` (`date`, `title`, `text`, `image`).

## Запуск на компьютере

Расписание загружается через `fetch`, поэтому сайт, открытый двойным щелчком (`file://`), его не покажет. Запустите локальный сервер:

```bash
cd hram
python3 -m http.server 8000
# открыть http://localhost:8000
```

## План админки

Сайт уже устроен так, что админке нужно только редактировать `data/schedule.json` и `data/news.json`. Вёрстку трогать не придётся. Есть два пути.

1. **Decap CMS** (бывший Netlify CMS). Это бесплатная админка без своего сервера: в папку `admin/` кладутся два файла, и в браузере появляется форма «Добавить день / службу». Каждое сохранение — коммит в репозиторий. Подходит, если сайт живёт на GitHub Pages / Netlify и у редакторов есть доступ к GitHub.
2. **Небольшой собственный бэкенд** (PHP или Node + SQLite) на обычном российском хостинге (Beget, Timeweb и т. п.). Он даёт страницу входа для настоятеля или секретаря, форму расписания и сохраняет тот же JSON (или отдаёт его по адресу `/api/schedule`). Этот путь надёжнее, если сервисы GitHub/Netlify из Крыма открываются нестабильно.

В обоих случаях фронтенд менять не нужно, кроме, возможно, адреса в `assets/js/schedule.js` (`load('data/schedule.json')`).
